# Selenite Legal

A static legal website for the Selenite Discord bot, covering the public Terms of Use, Privacy Policy, and supporting landing page.

Live pages:

- Home: `https://quantum-sharkware.github.io/selenite-legal/`
- Terms of Use: `https://quantum-sharkware.github.io/selenite-legal/terms/`
- Privacy Policy: `https://quantum-sharkware.github.io/selenite-legal/privacy/`

## Overview

This project is a lightweight Next.js site that presents Selenite’s legal documents in a polished, readable format.
The site includes:

- a landing page summarizing Selenite’s legal and privacy posture
- a dedicated Terms of Use page
- a dedicated Privacy Policy page

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Static export via `next.config.ts`
- Node.js 20.9+ required
